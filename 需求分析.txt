============================================================
CropGPT 教师端 & 学生端 & 研究者端 · 功能需求（植保场景）
============================================================

一、教师端（五模块）
------------------------------------------------------------

侧边栏导航：

  教案
  课程
  　├─ 题库
  　├─ 布置作业
  　├─ 布置考试
  　├─ 批改作业
  　├─ 批改考试
  　└─ 批改实习报告 ★
  讨论
  通知
  资料
  学情

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【1. 制作】

  教案  AI辅助生成植保教学章节（后续扩展PPT、视频制作）

【2. 课程】

  创建课程 + 章节管理 + 学生名单 + 加课码加入
  课程是后续布置和批改的前置条件

【3. 布置】（课程下的子功能）

  题库       图文题 · 病虫害识别题 · 病例题
  布置作业   从题库选题 → 设定截止时间 → 分发到班级
  布置考试   限时组卷 → 设定防作弊规则 → 自动阅卷

【4. 批改】（课程下的子功能）

  批改作业       文本题 AI 预批 + 人工复批 + 评语
  批改考试       自动评分 + 成绩列表 + 错题解析
  批改实习报告 ★ 学生上传田间/实
  验室病害图像
                   → CropGPT 视觉诊断（图像特征提取+病害识别）
                   → 通用大模型逻辑评估（诊断推理链+规范性评分）
                   → 综合评分 + 评语

【5. 工具】

  讨论    答疑区管理 · 话题创建
  通知    群发提醒（作业截止·调课·公告）
  资料    拓展阅读上传管理 · 参考文件

【6. 学情】

  班级仪表盘       成绩分布 · 学业趋势
  常见错误聚类      全班薄弱知识点自动归类
  教学难点分布图    哪些知识点普遍掌握差
  个体预警          挂科风险学生标记
  分组建议          同质分组 / 异质分组教学策略推荐

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

教师端数据逻辑链：

  制作教案 → 课程绑定 → 题库出题 → 布置作业/考试
                                          │
                                          ↓
                                    学生提交答卷
                                          │
                                          ↓
                              ┌─ 文本题 → 通用大模型批改
                              ├─ 图像题 → CropGPT 视觉诊断
                              └─ 实习报告 → CropGPT + 通用模型双评
                                          │
                                          ↓
                                    批改结果入库
                                          │
                                          ↓
                              学情分析 ← 学生答题日志 + 批改数据
                                  │
                                  ├─ 班级知识图谱（薄弱点聚类）
                                  ├─ 教学难点分布图
                                  ├─ 个体预警（挂科风险）
                                  └─ 分组建议（同质/异质）

二、学生端（五页闭环）
============================================================

侧边栏导航：

  我的课程
  作业·考试
  辅导助手 ★（含场景练习）
  错题集
  学情分析

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【1. 我的课程】

  课程列表 + 章节学习（课件·视频·病害图谱）
  选课加入 → 学章节内容

【2. 作业·考试】

  两个 tab：日常作业 | 限时考试
  作答 → 交卷 → 查看批改评语 + 成绩

【3. 辅导助手】（CropGPT 核心差异化落地页）

  两个 tab：自由提问 | 场景练习

  自由提问（苏格拉底式引导）：
    学生上传田间病害图或文字提问
    → "你观察到什么特征？"
    → "回忆一下，这类病害有哪些主要区别点？"
    → "你的假设是什么？"
    → "怎么验证你的假设？"
    → "最终诊断结论是什么？"
    全程不直接给答案，观察→假设→验证→结论

  场景练习（复杂综合案例）：
    系统预设综合案例（如：某地块水稻出现异常症状）
    学生需要主动提问收集信息：
    → "土壤情况如何？" → 系统给数据
    → "发病叶片正面和背面分别是什么？" → 系统描述
    → "最近施药记录有吗？" → 系统给记录
    → 最终给出诊断 + 处理方案
    系统评估学生提问质量 + 诊断准确性

【4. 错题集】

  自动归集答错的题目
  每次错题展示：
    ├─ 原题 + 当时提交的答案
    ├─ ★ 错误推理路径回放（不是看答案，是看当时怎么想的）
    ├─ 正确答案 + 解析
    └─ "靶向练习" 按钮 → 跳转到相关辨析题
  支持按知识点、时间范围筛选

【5. 学情分析】

  个人视角的学习数据：
    ├─ 知识点薄弱项热力图
    ├─ 学习投入曲线（时长·任务完成·得分趋势）
    ├─ 认知薄弱点预警
    └─ ★ 学习任务包
         ├─ 错题（含错误推理链）
         ├─ 薄弱知识点的关键点卡片
         ├─ 相关辨析题
         └─ 靶向强化练习推荐

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

学生端数据逻辑链：

  选课加入 → 学章节内容 → 做作业/考试
                                │
                                ↓
                  遇到不会的 → 辅导助手
                      │           │
                      │  ┌─ 自由提问：苏格拉底引导
                      │  └─ 场景练习：主动提问→诊断评估
                      │           │
                      ↓           ↓
                  提交答卷 → 等待批改 → 查看成绩+评语
                      │
                      ↓
                答题日志入库 → 错题自动归集到错题集
                      │
                      ↓
                学情分析引擎 → 生成学习任务包
                      │         ├─ 错题+错误推理链
                      │         ├─ 知识点关键卡片
                      │         ├─ 辨析题
                      │         └─ 靶向练习推荐
                      │
                      ↓
                回到课程/错题集补强 → 再次答题 → 循环闭环

四、研究者端（五步流程）
============================================================

侧边栏导航：

  AI 研究助手
  文献检索
  文献库
  写作助手
  研究热点
  研究成果

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

【1. AI 研究助手】

  类似学生端的辅导助手，但服务于学术研究
  植保场景：病虫害机理探索、防治方案论证、作物病理分析
  多智能体矩阵切换（通用·植保专项·数据分析）
  对话产物可一键保存为研究成果

【2. 文献检索】

  多源学术搜索（CrossRef·Semantic Scholar 等）
  关键词检索 + 筛选（年份·期刊·领域·影响因子）
  一键导入文献到文献库

【3. 文献库】

  已收藏文献的列表管理
  点击进入文献精读页：
    ├─ PDF 原文浏览
    ├─ AI 自动摘要 + 关键论据提取
    ├─ 段落级标注与批注
    └─ 论据追溯至原文出处

【4. 写作助手】

  LaTeX 在线编辑 + 实时编译预览
  附件管理（图表·参考文献 .bib）
  AI 辅助润色·扩写·摘要生成

【5. 研究热点】

  前沿课题雷达：领域热度·文献密度·跨学科交叉追踪
  热点看板可视化
  植保场景可切换细分领域（病害·虫害·农药·生态）

【6. 研究成果】

  从 AI 研究助手 / 写作助手保存的输出物统一管理
  支持分类、标签、项目归档
  结论可追溯至原始对话或论文出处

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

研究者端数据逻辑链：

  发现（检索+热点）→ 阅读（文献库+精读）→ 分析（AI研究助手+工具箱）
       │                    │                       │
       │    文献入库 ←── 筛选保存 ──→ 精读批注      │
       │                    │                       │
       ↓                    ↓                       ↓
  追踪前沿课题        论据抽取+原文追溯       AI 对话论证+数据分
       │                    │                       │
       └────────────────────┼───────────────────────┘
                            │
                            ↓
                     写作助手（LaTeX）
                      论文初稿 → 润色 → 编译 → 定稿
                            │
                            ↓
                     研究成果（归档·标签·追溯）
