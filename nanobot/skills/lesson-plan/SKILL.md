# 智能教案工坊

为教师生成结构化、专业、可直接使用的教案。

## 工作流程

### 1. 收集信息

生成教案前，确认以下关键信息（缺失则主动询问）：

| 必需 | 可选（有则更好） |
|------|-----------------|
| 学科 | 目标学生水平（快班/慢班/全英班） |
| 年级 | 教学风格偏好 |
| 课题/知识点 | 课时安排 |
| | 已有教材或参考资料 |

### 2. 生成教案

按 [教案模板](references/lesson-plan-template.md) 输出，包含：

- **基本信息**：学科、年级、课题、课时
- **教学目标**：知识目标、能力目标、素养目标（三维目标）
- **教学重难点**：重点 + 难点 + 突破策略
- **教学过程**：
  - 导入（5min）— 情境创设
  - 新授（25min）— 核心知识讲解 + 互动设计
  - 练习（10min）— 分层练习
  - 总结（5min）— 知识梳理 + 作业布置
- **板书设计**
- **教学反思预设**

### 3. 三大特色功能

#### 风格迁移

用户指定模仿对象时，调整教案风格：

| 名师风格 | 特征 | 调整方向 |
|---------|------|---------|
| 于漪 | 情感浸润，以情动人 | 增加情境渲染、情感铺垫 |
| 魏书生 | 自主管理，学生主导 | 增加学生自主活动、小组合作 |
| 黄爱华 | 数学思维，问题驱动 | 增加问题链、思维阶梯 |
| 李镇西 | 民主教育，对话启发 | 增加开放性讨论、师生对话 |
| 任勇 | 竞赛思维，拓展提升 | 增加变式训练、一题多解 |

用户指定其他名师时，搜索该教师的教学理念和典型课例，提取风格特征后应用。

#### 差异化版本

用户要求差异化时，基于同一教案生成多个版本：

- **快班版**：提高思维深度，增加拓展题和开放性问题，减少基础重复练习
- **慢班版**：强化基础，增加脚手架和分步引导，降低抽象程度
- **全英版**：保留教学逻辑，用英文重写，术语附中文注释，增加语言支架

每个版本标注差异点（用 `> 差异：...` 标注）。

#### 跨学科融合

用户询问融合可能性时：

1. 分析当前课题的知识内核
2. 识别可关联的学科和知识点
3. 设计一个具体的融合活动（10-15min）
4. 说明融合的教学价值和可行性

## 输出规范

- 语言：中文（全英版除外）
- 格式：Markdown，层级清晰
- 长度：单课时教案 1500-2500 字
- 口吻：专业但不晦涩，同行可直接使用

## 注意事项

- 不编造具体教材页码或课标编号
- 涉及敏感历史或政治内容时保持客观中立
- 生成练习题时标注难度层级
- 如果用户提供了教材内容或参考资料，优先基于实际材料生成
