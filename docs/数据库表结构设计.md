## 1. 概述

### 1.3 命名规范

- **表名**: 小写复数形式，下划线分隔 (如 `users`, `course_members`)
- **字段名**: 小写下划线分隔 (如 `user_id`, `course_name`)
- **主键**: `id` 或 `{表名}_id`
- **外键**: `{引用表名}_id`
- **索引**: `idx_{表名}_{字段名}`
- **唯一约束**: `uq_{表名}_{字段名}`
- **检查约束**: `chk_{表名}_{字段名}`

### 1.4 数据类型映射

| 用途 | 数据库类型 | Python类型 | 说明 |
|------|-----------|-----------|------|

## 2. 用户表 (users)

### 2.1 表说明

存储系统中的所有用户信息，包括教师、学生和研究者。支持密码认证和账户安全功能。

### 2.2 表结构

```sql
CREATE TABLE users (
    -- ========== 主键 ==========
    role                VARCHAR(20)     NOT NULL,           -- 用户角色
    user_id             VARCHAR(64)     NOT NULL,           -- 用户ID
    
    -- ========== 基本信息 ==========
    display_name        VARCHAR(100)    NOT NULL,           -- 显示名称
    
    -- ========== 认证信息 ==========
    password_hash       VARCHAR(255)    NOT NULL,           -- 密码哈希
    password_salt       VARCHAR(64)     NOT NULL,           -- 密码盐值
    email               VARCHAR(200),                       -- 邮箱（可选，用于找回密码）
    
    -- ========== 安全信息 ==========
    last_login_at       TIMESTAMPTZ,                        -- 最后登录时间
    last_login_ip       VARCHAR(45),                        -- 最后登录IP
    login_attempts      INTEGER         DEFAULT 0,          -- 登录尝试次数
    locked_until        TIMESTAMPTZ,                        -- 锁定到期时间
    
    -- ========== 扩展信息 ==========
    profile             JSONB           DEFAULT '{}',       -- 个人信息
    settings            JSONB           DEFAULT '{}',       -- 用户设置
    
    -- ========== 状态信息 ==========
    is_active           BOOLEAN         DEFAULT TRUE,       -- 是否激活
    is_verified         BOOLEAN         DEFAULT FALSE,      -- 是否验证邮箱
    
    -- ========== 时间戳 ==========
    registered_at       TIMESTAMPTZ     DEFAULT NOW(),      -- 注册时间
    updated_at          TIMESTAMPTZ     DEFAULT NOW(),      -- 更新时间
    
    -- ========== 约束 ==========
    CONSTRAINT pk_users PRIMARY KEY (role, user_id),
    CONSTRAINT chk_users_role CHECK (role IN ('teacher', 'student', 'researcher')),
    CONSTRAINT chk_users_login_attempts CHECK (login_attempts >= 0)
);
```

### 2.3 字段说明

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| role | VARCHAR(20) | ✓ | - | 用户角色：teacher(教师)/student(学生)/researcher(研究者) |
| user_id | VARCHAR(64) | ✓ | - | 用户唯一标识，最大64字符 |
| display_name | VARCHAR(100) | ✓ | - | 用户显示名称 |
| password_hash | VARCHAR(255) | ✓ | - | 密码哈希值（使用 bcrypt/argon2） |
| password_salt | VARCHAR(64) | ✓ | - | 密码盐值 |
| email | VARCHAR(200) | ✗ | - | 邮箱地址（可选，用于找回密码） |
| last_login_at | TIMESTAMPTZ | ✗ | - | 最后登录时间 |
| last_login_ip | VARCHAR(45) | ✗ | - | 最后登录IP地址 |
| login_attempts | INTEGER | ✗ | 0 | 连续登录失败次数 |
| locked_until | TIMESTAMPTZ | ✗ | - | 账户锁定到期时间 |
| profile | JSONB | ✗ | '{}' | 个人信息（头像、简介、联系方式等） |
| settings | JSONB | ✗ | '{}' | 用户设置（主题、语言、通知等） |
| is_active | BOOLEAN | ✗ | TRUE | 账户是否激活 |
| is_verified | BOOLEAN | ✗ | FALSE | 邮箱是否已验证 |
| registered_at | TIMESTAMPTZ | ✓ | NOW() | 注册时间 |
| updated_at | TIMESTAMPTZ | ✓ | NOW() | 最后更新时间 |

### 2.4 密码安全设计

**密码哈希算法：**
- 推荐使用 **bcrypt** 或 **argon2**
- 成本因子：bcrypt rounds=12 或 argon2 iterations=3

**密码存储示例：**
```python
import bcrypt

# 注册时
password = "user_password"
salt = bcrypt.gensalt(rounds=12)
password_hash = bcrypt.hashpw(password.encode('utf-8'), salt)

# 验证时
is_valid = bcrypt.checkpw(password.encode('utf-8'), password_hash)
```

**账户锁定策略：**
- 连续登录失败 5 次，锁定账户 30 分钟
- 锁定时间递增：5次=30分钟，10次=1小时，15次=24小时

### 2.9 登录验证流程

```
┌─────────────────────────────────────────────────────────────┐
│                      登录验证流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 用户输入 user_id + password + role                       │
│                                                              │
│  2. 查询用户                                                  │
│     SELECT * FROM users                                      │
│     WHERE user_id = ? AND role = ? AND is_active = TRUE      │
│                                                              │
│  3. 检查账户是否被锁定                                         │
│     IF locked_until IS NOT NULL AND locked_until > NOW()     │
│         THEN 返回错误"账户已锁定"                             │
│                                                              │
│  4. 验证密码                                                  │
│     bcrypt.checkpw(password, password_hash)                  │
│                                                              │
│  5. 验证成功                                                  │
│     ├── 更新 last_login_at = NOW()                           │
│     ├── 更新 last_login_ip = ?                               │
│     ├── 重置 login_attempts = 0                              │
│     └── 返回 JWT Token                                       │
│                                                              │
│  6. 验证失败                                                  │
│     ├── login_attempts += 1                                  │
│     ├── IF login_attempts >= 5                               │
│     │   THEN locked_until = NOW() + 30 minutes               │
│     └── 返回错误"用户名或密码错误"                            │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

### 2.10 密码找回流程

```
┌─────────────────────────────────────────────────────────────┐
│                      密码找回流程                            │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 用户输入 email                                           │
│                                                              │
│  2. 查询用户                                                  │
│     SELECT * FROM users                                      │
│     WHERE email = ? AND is_active = TRUE                     │
│                                                              │
│  3. 生成重置令牌                                              │
│     reset_token = uuid4()                                    │
│     reset_token_expires = NOW() + 1 hour                     │
│                                                              │
│  4. 存储令牌（可在 profile 或单独表）                         │
│     UPDATE users SET profile = profile || '{                 │
│         "reset_token": "...",                                │
│         "reset_token_expires": "..."                         │
│     }' WHERE user_id = ?                                     │
│                                                              │
│  5. 发送重置邮件                                              │
│     发送包含 reset_token 的邮件到用户邮箱                     │
│                                                              │
│  6. 用户点击链接，输入新密码                                   │
│                                                              │
│  7. 验证令牌                                                  │
│     IF reset_token_expires > NOW()                           │
│         THEN 更新密码                                         │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

## 3. 课程表 (courses)

### 3.1 表说明

存储课程的基本信息，包括课程名称、学科、年级等。

### 3.2 表结构

```sql
CREATE TABLE courses (
    -- ========== 主键 ==========
    course_id           VARCHAR(12)     NOT NULL,           -- 课程ID
    
    -- ========== 基本信息 ==========
    course_name         VARCHAR(200)    NOT NULL,           -- 课程名称
    subject             VARCHAR(50)     NOT NULL,           -- 学科
    grade               VARCHAR(20)     NOT NULL,           -- 年级
    description         TEXT,                               -- 课程描述
    
    -- ========== 教师信息 ==========
    teacher_id          VARCHAR(64)     NOT NULL,           -- 教师ID
    teacher_role        VARCHAR(20)     NOT NULL DEFAULT 'teacher', -- 教师角色
    teacher_name        VARCHAR(100)    NOT NULL,           -- 教师姓名
    
    -- ========== 课程设置 ==========
    join_code           VARCHAR(6)      NOT NULL,           -- 加入码
    is_public           BOOLEAN         DEFAULT FALSE,      -- 是否公开
    member_count        INTEGER         DEFAULT 0,          -- 成员数量
    
    -- ========== 扩展数据 ==========
    metadata            JSONB           DEFAULT '{}',       -- 元数据
    settings            JSONB           DEFAULT '{}',       -- 课程设置
    
    -- ========== 时间戳 ==========
    created_at          TIMESTAMPTZ     DEFAULT NOW(),      -- 创建时间
    updated_at          TIMESTAMPTZ     DEFAULT NOW(),      -- 更新时间
    
    -- ========== 约束 ==========
    CONSTRAINT pk_courses PRIMARY KEY (course_id),
    CONSTRAINT fk_courses_teacher FOREIGN KEY (teacher_id, teacher_role) 
        REFERENCES users(user_id, role) ON DELETE CASCADE,
    CONSTRAINT uq_courses_join_code UNIQUE (join_code),
    CONSTRAINT chk_courses_subject CHECK (subject IN (
        '农学', '园艺', '植物保护', '土壤肥料', 
        '智慧农业', '畜牧兽医', '食品科学', '农业经济'
    )),
    CONSTRAINT chk_courses_grade CHECK (grade IN (
        '大一', '大二', '大三', '大四', '研一', '研二'
    )),
    CONSTRAINT chk_courses_member_count CHECK (member_count >= 0)
);
```

### 3.3 字段说明

| 字段名 | 类型 | 必填 | 默认值 | 说明 |
|--------|------|------|--------|------|
| course_id | VARCHAR(12) | ✓ | - | 课程唯一标识，12位十六进制 |
| course_name | VARCHAR(200) | ✓ | - | 课程名称 |
| subject | VARCHAR(50) | ✓ | - | 学科类别 |
| grade | VARCHAR(20) | ✓ | - | 年级 |
| description | TEXT | ✗ | - | 课程详细描述 |
| teacher_id | VARCHAR(64) | ✓ | - | 创建教师的ID |
| teacher_role | VARCHAR(20) | ✓ | 'teacher' | 教师角色 |
| teacher_name | VARCHAR(100) | ✓ | - | 教师显示名称 |
| join_code | VARCHAR(6) | ✓ | - | 学生加入课程的6位数字码 |
| is_public | BOOLEAN | ✗ | FALSE | 是否公开可见 |
| member_count | INTEGER | ✗ | 0 | 已加入的学生数量 |
| metadata | JSONB | ✗ | '{}' | 扩展元数据 |
| settings | JSONB | ✗ | '{}' | 课程设置 |
| created_at | TIMESTAMPTZ | ✓ | NOW() | 创建时间 |
| updated_at | TIMESTAMPTZ | ✓ | NOW() | 更新时间 |

## 4. 课程成员表 (course_members)

### 4.1 表说明

记录课程与学生的关联关系，支持多次提交作业。

### 4.2 表结构

```sql
CREATE TABLE course_members (
    -- ========== 主键 ==========
    id                  SERIAL          NOT NULL,           -- 自增ID
    
    -- ========== 关联信息 ==========
    course_id           VARCHAR(12)     NOT NULL,           -- 课程ID
    user_id             VARCHAR(64)     NOT NULL,           -- 用户ID
    user_role           VARCHAR(20)     NOT NULL DEFAULT 'student', -- 用户角色
    
    -- ========== 成员信息 ==========
    display_name        VARCHAR(100)    NOT NULL,           -- 显示名称
    
    -- ========== 扩展数据 ==========
    metadata            JSONB           DEFAULT '{}',       -- 扩展数据
    
    -- ========== 时间戳 ==========
    joined_at           TIMESTAMPTZ     DEFAULT NOW(),      -- 加入时间
    
    -- ========== 约束 ==========
    CONSTRAINT pk_course_members PRIMARY KEY (id),
    CONSTRAINT fk_course_members_course FOREIGN KEY (course_id) 
        REFERENCES courses(course_id) ON DELETE CASCADE,
    CONSTRAINT fk_course_members_user FOREIGN KEY (user_id, user_role) 
        REFERENCES users(user_id, role) ON DELETE CASCADE,
    CONSTRAINT uq_course_member UNIQUE (course_id, user_id, user_role)
```

## 5. 教师个人教案库表 (teacher_lessons)

### 5.1 表说明

存储教师创建的个人教案，支持复用和公开分享。教师可以创建自己的教案库，教案可以被多个课程引用。

### 5.2 表结构

```sql
CREATE TABLE teacher_lessons (
    -- ========== 主键 ==========
    lesson_id           VARCHAR(12)     NOT NULL,           -- 教案ID
    
    -- ========== 关联信息 ==========
    teacher_id          VARCHAR(64)     NOT NULL,           -- 教师ID
    teacher_role        VARCHAR(20)     NOT NULL DEFAULT 'teacher', -- 教师角色
    
    -- ========== 基本信息 ==========
    title               VARCHAR(200)    NOT NULL,           -- 教案标题
    description         TEXT,                               -- 教案描述
    
    -- ========== 内容信息 ==========
    content_type        VARCHAR(20)     DEFAULT 'markdown', -- 内容类型
    content             TEXT,                               -- 教案内容
    content_hash        VARCHAR(64),                        -- 内容哈希
    
    -- ========== 分类信息 ==========
    subject             VARCHAR(50),                        -- 学科
    grade               VARCHAR(20),                        -- 年级
    tags                JSONB           DEFAULT '[]',       -- 标签
    
    -- ========== 共享设置 ==========
    is_public           BOOLEAN         DEFAULT FALSE,      -- 是否公开
    use_count           INTEGER         DEFAULT 0,          -- 使用次数
    
    -- ========== 扩展数据 ==========
    metadata            JSONB           DEFAULT '{}',       -- 元数据
    
    -- ========== 时间戳 ==========
    created_at          TIMESTAMPTZ     DEFAULT NOW(),      -- 创建时间
    updated_at          TIMESTAMPTZ     DEFAULT NOW(),      -- 更新时间
```

```sql
        REFERENCES courses(course_id) ON DELETE CASCADE,
    CONSTRAINT chk_homework_total_points CHECK (total_points >= 0)
);

-- ============================================================
-- 6. 题目表
-- ============================================================
CREATE TABLE questions (
    id                  SERIAL          NOT NULL,
    hw_id               VARCHAR(15)     NOT NULL,
    question_id         VARCHAR(20)     NOT NULL,
    question_type       VARCHAR(30)     NOT NULL,
    content             TEXT            NOT NULL,
    points              INTEGER         DEFAULT 0,
    answer              TEXT,
    options             JSONB,
    explanation         TEXT,
    metadata            JSONB           DEFAULT '{}',
    CONSTRAINT pk_questions PRIMARY KEY (id),
    CONSTRAINT fk_questions_homework FOREIGN KEY (hw_id) 
        REFERENCES homework(hw_id) ON DELETE CASCADE,
    CONSTRAINT uq_question_in_homework UNIQUE (hw_id, question_id),
    CONSTRAINT chk_questions_type CHECK (question_type IN (
        'short_answer', 'long_answer', 'multiple_choice', 'multiple_select',
        'true_false', 'code', 'fill_blank', 'matching', 'essay'
    )),
    CONSTRAINT chk_questions_points CHECK (points >= 0)
);

-- ============================================================
-- 7. 提交表
-- ============================================================
CREATE TABLE submissions (
    id                  SERIAL          NOT NULL,
    hw_id               VARCHAR(15)     NOT NULL,
    student_id          VARCHAR(64)     NOT NULL,
    student_role        VARCHAR(20)     NOT NULL DEFAULT 'student',
    course_id           VARCHAR(12)     NOT NULL,
    attempt_number      INTEGER         DEFAULT 1,
    answers             JSONB           DEFAULT '{}',
    status              VARCHAR(20)     DEFAULT 'submitted',
    score               INTEGER         DEFAULT 0,
    feedback            JSONB           DEFAULT '{}',
    submitted_at        TIMESTAMPTZ     DEFAULT NOW(),
    graded_at           TIMESTAMPTZ,
    graded_by           VARCHAR(64),
    CONSTRAINT pk_submissions PRIMARY KEY (id),
    CONSTRAINT fk_submissions_homework FOREIGN KEY (hw_id) 
        REFERENCES homework(hw_id) ON DELETE CASCADE,
    CONSTRAINT fk_submissions_student FOREIGN KEY (student_id, student_role) 
        REFERENCES users(user_id, role) ON DELETE CASCADE,
    CONSTRAINT fk_submissions_course FOREIGN KEY (course_id) 
        REFERENCES courses(course_id) ON DELETE CASCADE,
    CONSTRAINT uq_submission_attempt UNIQUE (hw_id, student_id, attempt_number),
    CONSTRAINT chk_submissions_status CHECK (status IN (
        'submitted', 'grading', 'graded', 'returned'
    )),
    CONSTRAINT chk_submissions_score CHECK (score >= 0),
    CONSTRAINT chk_submissions_attempt CHECK (attempt_number >= 1)
);

    metadata            JSONB           DEFAULT '{}',

    updated_at          TIMESTAMPTZ     DEFAULT NOW(),
    CONSTRAINT pk_course_resources PRIMARY KEY (id),
    CONSTRAINT fk_course_resources_course FOREIGN KEY (course_id) 
        REFERENCES courses(course_id) ON DELETE CASCADE,
    CONSTRAINT chk_resources_type CHECK (resource_type IN (
        'file', 'link', 'video', 'audio', 'image', 'document'
    ))
);

-- 9. 学习进度表
-- ============================================================
CREATE TABLE learning_progress (
    id                  SERIAL          NOT NULL,
    student_id          VARCHAR(64)     NOT NULL,
    student_role        VARCHAR(20)     NOT NULL DEFAULT 'student',
    course_id           VARCHAR(12)     NOT NULL,
    lesson_id           VARCHAR(12)     NOT NULL,
    progress_percent    INTEGER         DEFAULT 0,
    status              VARCHAR(20)     DEFAULT 'not_started',
    time_spent          INTEGER         DEFAULT 0,
    metadata            JSONB           DEFAULT '{}',
    started_at          TIMESTAMPTZ,
    completed_at        TIMESTAMPTZ,
    last_accessed       TIMESTAMPTZ     DEFAULT NOW(),
    CONSTRAINT pk_learning_progress PRIMARY KEY (id),
    CONSTRAINT fk_progress_student FOREIGN KEY (student_id, student_role) 
        REFERENCES users(user_id, role) ON DELETE CASCADE,
    CONSTRAINT fk_progress_course FOREIGN KEY (course_id) 
        REFERENCES courses(course_id) ON DELETE CASCADE,
    CONSTRAINT fk_progress_lesson FOREIGN KEY (lesson_id) 
        REFERENCES lessons(lesson_id) ON DELETE CASCADE,
    CONSTRAINT uq_student_lesson UNIQUE (student_id, lesson_id),
    CONSTRAINT chk_progress_percent CHECK (progress_percent >= 0 AND progress_percent <= 100),
    CONSTRAINT chk_progress_status CHECK (status IN (
        'not_started', 'in_progress', 'completed', 'paused'
    )),
    CONSTRAINT chk_time_spent CHECK (time_spent >= 0)
);

CREATE TABLE notifications (

    related_type        VARCHAR(30),
    related_id          VARCHAR(64),

    metadata            JSONB           DEFAULT '{}',
    created_at          TIMESTAMPTZ     DEFAULT NOW(),
    CONSTRAINT pk_notifications PRIMARY KEY (id),
    CONSTRAINT fk_notifications_user FOREIGN KEY (user_id, user_role) 
        REFERENCES users(user_id, role) ON DELETE CASCADE,
    CONSTRAINT chk_notification_type CHECK (notification_type IN (
        'homework_new', 'homework_deadline', 'homework_graded',
        'course_new', 'course_update', 'course_join',
        'system', 'announcement'
    )),
    CONSTRAINT chk_related_type CHECK (related_type IS NULL OR related_type IN (
        'course', 'homework', 'lesson', 'submission', 'user'

CREATE OR REPLACE FUNCTION update_updated_at_column()
RETURNS TRIGGER AS $$
BEGIN
    NEW.updated_at = NOW();
    RETURN NEW;
END;
$$ language 'plpgsql';

-- 为需要的表创建触发器

    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

    FOR EACH ROW EXECUTE FUNCTION update_updated_at_column();

CREATE TRIGGER update_course_resources_updated_at BEFORE UPDATE ON course_resources
```
