# 教案：反向传播算法

## 基本信息

| 项目 | 内容 |
|------|------|
| 学科 | 机器学习 |
| 年级 | 大一 |
| 课题 | 反向传播算法（Backpropagation） |
| 课时 | 1课时（45分钟） |
| 前置知识 | 深度学习基本概念、神经网络结构、微积分（偏导数、链式法则） |
| 教材版本 | 自编讲义（参考《深度学习》Ian Goodfellow 第6.5节） |

## 教学目标

### 知识目标
1. 理解神经网络"训练"的本质——通过调整权重最小化损失函数
2. 掌握前向传播（Forward Propagation）的计算过程
3. 理解反向传播的核心思想——利用链式法则高效计算梯度
4. 能够手动计算一个简单网络的反向传播过程

### 能力目标
1. 能够对单层或多层网络进行前向传播和反向传播的数值计算
2. 能够解释梯度下降与反向传播的协作关系
3. 初步具备分析网络训练过程中梯度变化的能力

### 素养目标
1. 体会"化繁为简"的数学思想——将复杂网络的梯度计算分解为局部运算
2. 培养严谨的数学推导习惯和工程化思维
3. 理解算法效率对大规模模型训练的重要性

## 教学重难点

### 重点
1. 反向传播的链式法则推导过程
2. 损失函数对权重的偏导数计算
3. 前向传播与反向传播的对应关系

### 难点
1. 多层网络中梯度逐层传递的逻辑理解
2. "计算图"视角下反向传播的全局理解
3. 避免链式法则连乘时的常见计算错误

### 突破策略
1. **数值先行**：先用具体数字完整演示一遍计算过程，再抽象到公式
2. **计算图可视化**：用计算图将复合函数拆解为基本运算节点，每一步清晰可见
3. **分步脚手架**：将反向传播拆为"计算损失 → 求输出层梯度 → 求隐藏层梯度 → 更新权重"四步，逐步推进
4. **类比巩固**：用"责任追溯"类比——出了问题，从结果倒推每个环节的责任（梯度）

## 教学过程

### 一、导入环节（5分钟）

**情境创设：**

教师在黑板上画一个简单的两层神经网络（输入层2个节点、隐藏层2个节点、输出层1个节点），然后提问：

> "上节课我们知道了深度学习能够自动学习特征。但这个网络一开始的权重是随机的，输出结果肯定不准确。那么问题来了——**网络是怎么'学会'正确答案的？**"

引导学生回忆"训练"的概念，引出核心问题：

> "训练 = 不断调整权重使预测更准确。那**怎么知道每个权重该调多少、往哪个方向调？**这就是今天要学的——**反向传播算法**。"

**设计意图：**
从上节课的知识衔接出发，以问题链驱动思考，让学生带着"如何训练网络"的明确目标进入新课。

---

### 二、新授环节（28分钟）

#### 环节1：前向传播回顾与损失函数（8分钟）

- **教师活动：**

  以一个具体数值网络为例（贯穿全课）：

  ```
  网络结构：输入(x₁=0.5, x₂=0.8) → 隐藏层(h₁, h₂) → 输出(ŷ)
  初始权重：w₁=0.1, w₂=0.3, w₃=0.2, w₄=0.4, w₅=0.5, w₆=0.6
  激活函数：sigmoid  σ(z) = 1/(1+e⁻ᶻ)
  真实标签：y = 1
  ```

  带领学生逐步计算前向传播：

  - 隐藏层：z₁ = w₁·x₁ + w₂·x₂，h₁ = σ(z₁)；z₂ = w₃·x₁ + w₄·x₂，h₂ = σ(z₂)
  - 输出层：z₃ = w₅·h₁ + w₆·h₂，ŷ = σ(z₃)
  - 损失函数（均方误差）：L = ½(y - ŷ)²

  **边算边写**，每一步都写出中间结果。

- **学生活动：**
  - 跟随教师在纸上同步计算，记录每一步的中间值

- **设计意图：**
  用具体数字消除抽象感，确保每个学生都能跟上前向传播的完整过程，为反向传播奠定计算基础。

#### 环节2：反向传播核心推导（14分钟）

- **教师活动：**

  **（1）引入核心问题（2分钟）**

  > "前向传播告诉我们当前预测是多少、损失是多少。但训练需要知道：**每个权重对损失的影响有多大？** 数学上就是求 ∂L/∂w。"

  引入链式法则的回顾：
  > "如果 L = f(ŷ)，ŷ = g(w)，那么 ∂L/∂w = ∂L/∂ŷ × ∂ŷ/∂w。这就是链式法则，也是反向传播的数学基础。"

  **（2）计算图视角（3分钟）**

  在黑板上画出从输入到损失的计算图，将每个运算（加法、sigmoid、平方）标为一个节点，箭头表示数据流向。

  > "反向传播就是**沿着计算图从右往左（从损失到输入），逐节点应用链式法则**。"

  **（3）逐层梯度计算（9分钟）**

  以同一数值网络为例，带学生逐步计算：

  **① 输出层权重梯度：**

  - ∂L/∂ŷ = -(y - ŷ) = -(1 - ŷ) （代入具体数值）
  - ∂ŷ/∂z₃ = ŷ(1 - ŷ) （sigmoid导数）
  - ∂z₃/∂w₅ = h₁，∂z₃/∂w₆ = h₂
  - 因此：∂L/∂w₅ = ∂L/∂ŷ · ∂ŷ/∂z₃ · ∂z₃/∂w₅ （写出最终数值）

  > **强调**："看到了吗？梯度像接力棒一样，从损失 → 输出 → 隐藏层 → 权重，一棒一棒传回来。"

  **② 隐藏层权重梯度：**

  - ∂L/∂h₁ = ∂L/∂z₃ · ∂z₃/∂h₁ = ∂L/∂z₃ · w₅
  - ∂h₁/∂z₁ = h₁(1 - h₁)
  - ∂z₁/∂w₁ = x₁，∂z₁/∂w₂ = x₂
  - 因此：∂L/∂w₁ = ∂L/∂h₁ · ∂h₁/∂z₁ · ∂z₁/∂w₁

  **③ 权重更新：**

  > "有了梯度，就可以用梯度下降更新权重：w_new = w_old - η · ∂L/∂w"

  设学习率 η = 0.5，计算 w₅ 的新值。

- **学生活动：**
  - 在计算图上用彩色笔标注梯度流动方向
  - 同步计算 w₆ 和 w₁ 的梯度及更新值（教师巡视指导）

- **设计意图：**
  "计算图 + 数值计算"双管齐下，既建立全局直觉又确保计算能力。分步脚手架降低认知负荷。

#### 环节3：反向传播的全局视角（6分钟）

- **教师活动：**

  总结反向传播的四步流程，以流程图形式呈现：

  ```
  Step 1: 前向传播 → 计算所有节点的输出值
  Step 2: 计算损失 → L = ½(y - ŷ)²
  Step 3: 反向传播 → 从输出层到输入层，逐层计算梯度 ∂L/∂w
  Step 4: 更新权重 → w = w - η · ∂L/∂w
  ```

  补充两个重要概念：

  - **计算效率**：反向传播的计算复杂度与前向传播同阶（O(n)），远优于逐权重数值求导（O(n²)）——这正是1986年Rumelhart等人推广BP算法的意义
  - **梯度的物理含义**：∂L/∂w 表示"w变化一个微小量时，L大约变化多少"——正梯度说明w需要减小，负梯度说明w需要增大

- **学生活动：**
  - 在笔记本上用自己的话总结"反向传播是什么"（一句话）

- **设计意图：**
  从全局视角梳理算法流程，帮助学生形成完整认知框架；强调计算效率说明算法的实际价值。

---

### 三、练习环节（8分钟）

**基础练习（4分钟）——个人作答：**

给定如下极简网络（无隐藏层，直接从输入到输出）：

```
输入：x = 2，权重：w = 0.5，激活函数：线性（即 ŷ = w·x）
真实值：y = 3，损失函数：L = ½(y - ŷ)²
学习率：η = 0.1
```

问题：
1. 计算前向传播结果 ŷ 和损失 L
2. 计算 ∂L/∂w
3. 计算更新后的 w_new

**拓展练习（4分钟）——小组讨论：**

> 在一个3层网络的训练中，小明发现靠近输出层的权重更新很快，但靠近输入层的权重几乎不变。请用反向传播的知识解释可能的原因。

（参考答案方向：梯度消失问题——链式法则中多层sigmoid导数连乘，每项都小于0.25，乘积趋近于0）

**设计意图：**
基础练习巩固核心计算能力；拓展练习为后续"梯度消失与梯度爆炸"课程埋下伏笔，培养学生的问题分析能力。

---

### 四、总结环节（4分钟）

**知识梳理：**

教师带领学生回顾核心要点：

```
反向传播算法
├── 目标：高效计算损失函数对所有权重的梯度
├── 数学基础：链式法则（复合函数求导）
├── 核心流程：
│   ├── ① 前向传播 → 计算预测值和损失
│   ├── ② 反向传播 → 逐层计算梯度
│   └── ③ 梯度下降 → 更新权重
├── 计算图：将复杂计算分解为基本节点
└── 关键意义：与梯度下降配合，实现网络的"学习"
```

## 教学反思预设

- **预期难点：**
  - 多层网络中梯度的链式法则连乘容易出现计算错误，特别是sigmoid导数的计算
  - 部分学生可能混淆"∂L/∂w"和"w本身更新方向"的关系（符号问题）
  - 隐藏层梯度的计算需要"上游梯度 × 本地梯度"的拆解思维，初次接触可能不适应

- **应急方案：**
  - 若学生对链式法则计算跟不上，可临时简化网络为"无隐藏层"的单层网络，先完成全流程计算，再过渡到多层
  - 若时间不足，可将"拓展练习"调整为课后思考题，并在下次课开头用5分钟讨论

- **改进方向：**
  - 后续可安排一次NumPy编程实验，让学生用代码实现反向传播，对比手算结果验证正确性
  - 可引入"梯度检验"（Gradient Checking）方法，用数值微分验证反向传播梯度的正确性，培养工程化思维
  - 下一课时可自然衔接"梯度消失与梯度爆炸"问题，以及Adam等优化器的引入
