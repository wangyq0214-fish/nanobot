# 教案：深度学习介绍

## 基本信息

| 项目 | 内容 |
|------|------|
| 学科 | 机器学习 |
| 年级 | 大一 |
| 课题 | 深度学习介绍 |
| 课时 | 1课时（45分钟） |
| 教材版本 | 自编讲义（参考《深度学习》Ian Goodfellow 等著） |

## 教学目标

### 知识目标
1. 理解深度学习的基本概念及其在人工智能体系中的定位
2. 掌握神经网络的基本结构（输入层、隐藏层、输出层）和工作原理
3. 了解深度学习与传统机器学习的核心区别
4. 认识常见的深度学习模型类型（CNN、RNN、Transformer）

### 能力目标
1. 能够用通俗语言解释深度学习的基本原理
2. 能够判断哪些问题适合用深度学习方法解决
3. 初步具备阅读深度学习相关科普文献的能力

### 素养目标
1. 建立对人工智能技术的科学认知，形成理性看待技术发展的态度
2. 激发对机器学习领域的学习兴趣和探索欲望
3. 培养计算思维，学会从数据驱动的角度思考问题

## 教学重难点

### 重点
1. 神经网络的基本结构与信息传递过程
2. 深度学习"深度"的含义——多层非线性变换的特征提取思想
3. 深度学习与传统机器学习的区别

### 难点
1. 理解"端到端学习"和"自动特征提取"的概念
2. 感知深度学习模型的强大能力与其"黑箱"特性之间的关系

### 突破策略
1. **类比教学**：用"人脑神经元"类比人工神经元，用"流水线工厂"类比多层网络的信息处理
2. **可视化演示**：通过神经网络结构图和特征可视化图片帮助学生建立直觉
3. **案例驱动**：以人脸识别、语音助手等贴近生活的应用引入，降低抽象概念的理解门槛

## 教学过程

### 一、导入环节（5分钟）

**情境创设：**

播放一段30秒的短视频，展示深度学习在日常生活中的应用场景——手机人脸解锁、智能语音助手对话、AI绘画生成等。

教师提问：
> "这些令人惊叹的AI应用背后，都有一个共同的技术引擎，大家知道是什么吗？"

引导学生自由发言，最终引出主题——**深度学习（Deep Learning）**。

**设计意图：**
通过贴近学生日常的AI应用场景激发学习兴趣，建立"技术与生活相关"的认知，为后续理论讲解做好心理铺垫。

---

### 二、新授环节（25分钟）

#### 环节1：从机器学习到深度学习（8分钟）

- **教师活动：**
  - 以树状图梳理人工智能 → 机器学习 → 深度学习的层级关系
  - 讲解传统机器学习的工作流程：**人工提取特征 → 模型学习 → 预测输出**
  - 引出深度学习的核心革新：**让机器自己学习特征**
  - 用一张对比表格总结两者区别：

    | 对比维度 | 传统机器学习 | 深度学习 |
    |---------|------------|---------|
    | 特征提取 | 人工设计 | 自动学习 |
    | 数据需求 | 较少 | 大量 |
    | 模型复杂度 | 较低 | 高（多层结构） |
    | 可解释性 | 较强 | 较弱（黑箱） |
    | 典型算法 | SVM、决策树 | CNN、RNN、Transformer |

- **学生活动：**
  - 观察对比表格，思考并回答："如果要识别一张图片中有没有猫，传统方法和深度学习方法分别会怎么做？"

- **设计意图：**
  通过对比帮助学生建立清晰的技术脉络，用"识别猫"的实例将抽象概念具象化。

#### 环节2：神经网络的基本结构（10分钟）

- **教师活动：**
  - 展示单个人工神经元的结构图：输入 → 加权求和 → 激活函数 → 输出
  - 类比讲解："就像你期末成绩 = 平时分×30% + 考试分×70%，再通过一个'是否及格'的判定函数得出最终结果"
  - 展示多层神经网络结构图（输入层 → 隐藏层 → 输出层），讲解信息的前向传播过程
  - 强调"深度"的含义：**隐藏层越多，网络越"深"，能学习的特征越抽象**

- **学生活动：**
  - 在纸上画出一个简单的3层神经网络（输入层3个节点、隐藏层4个节点、输出层2个节点），标注信息流向

- **设计意图：**
  通过类比降低抽象门槛，手绘网络结构帮助学生加深对网络拓扑的理解。

#### 环节3：深度学习的典型模型与应用（7分钟）

- **教师活动：**
  - 用"一图一应用"的方式快速介绍三大经典模型：

    | 模型 | 全称 | 擅长领域 | 典型应用 |
    |------|------|---------|---------|
    | CNN | 卷积神经网络 | 图像处理 | 人脸识别、医学影像 |
    | RNN | 循环神经网络 | 序列数据 | 语音识别、机器翻译 |
    | Transformer | 变换器网络 | 长序列建模 | ChatGPT、AI写作 |

  - 展示一张Transformer架构的简化示意图，说明其"注意力机制"的核心思想（点到为止，不做深入推导）

- **学生活动：**
  - 快速抢答：以下场景应该用哪种模型？（①自动驾驶中的行人检测 → CNN；②智能客服对话 → Transformer；③股票价格趋势预测 → RNN）

- **设计意图：**
  帮助学生建立"模型-应用"的关联认知，为后续深入学习各模型打下基础。

---

### 三、练习环节（10分钟）

**基础练习（5分钟）：**

判断题（学生举手或用答题工具作答）：
1. 深度学习是机器学习的一个子领域。（ ✅ ）
2. 深度学习一定比传统机器学习效果好。（ ❌ ）
3. 神经网络的"深度"指的是输入数据的维度很高。（ ❌ ）
4. 深度学习需要大量标注数据才能训练出好模型。（ ✅ ）

**拓展练习（5分钟）：**

小组讨论题（3-4人一组）：
> 假设你是一家外卖平台的算法工程师，老板要求你用深度学习技术提升用户体验。请从以下至少两个角度设计方案：
> ① 推荐系统（给用户推荐可能喜欢的餐厅）
> ② 配送时间预估
> ③ 用户评论情感分析
>
> 要求：说明可以用哪种模型、需要什么数据、可能面临什么挑战。

每组选一位代表用1分钟简要分享。

**设计意图：**
基础练习巩固核心概念，拓展练习培养学生将理论联系实际的能力和团队协作意识。

---

### 四、总结环节（5分钟）

**知识梳理：**

教师带领学生回顾本节课的知识脉络，以思维导图形式呈现：

```
深度学习介绍
├── 定位：人工智能 → 机器学习 → 深度学习
├── 核心思想：自动特征提取、端到端学习
├── 基本结构：神经元 → 神经网络 → 深层网络
├── 经典模型：CNN / RNN / Transformer
└── 关键特点：数据驱动、多层抽象、黑箱特性
```

**作业布置：**

- **必做：** 阅读一篇关于深度学习发展史的科普文章（教师课后推送链接），写200字阅读笔记，重点记录你印象最深的一个里程碑事件。
- **选做：** 尝试用 Python 运行一个简单的神经网络示例代码（教师提供 Google Colab 链接，无需本地安装），观察训练过程中损失函数的变化，并截图提交。

## 教学反思预设

- **预期难点：**
  - 大一学生可能对"激活函数"、"前向传播"等术语感到陌生，需要用大量类比和可视化辅助
  - "端到端学习"和"自动特征提取"是本课最抽象的概念，部分学生可能理解不透彻

- **应急方案：**
  - 若学生对神经网络结构理解困难，可临时增加一个"人工模拟神经网络"的课堂小游戏：让几位学生扮演神经元，传递纸条（数据）并按规则（激活函数）决定是否继续传递
  - 若时间不足，可将"拓展练习"的小组讨论调整为课后思考题

- **改进方向：**
  - 后续课程可安排一次上机实验，让学生亲手搭建并训练一个简单的神经网络，将本节课的理论认知转化为实践体验
  - 可补充深度学习伦理方面的讨论（如AI换脸、算法偏见），提升学生的科技素养和社会责任感
